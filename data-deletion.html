Principe

CryptoScan ne crée aucun compte et ne dispose d'aucun serveur stockant vos données. Toutes les informations saisies dans l'application (adresses publiques, libellés, historique des relevés, préférences, clés d'API optionnelles) restent exclusivement dans la base de données locale de votre appareil.

Conséquence : la suppression est immédiate et totale. Il suffit d'effacer les données de l'application sur votre appareil. Aucune copie distante n'existe.

Supprimer les données locales

  • Depuis l'application : ouvrez Réglages, puis utilisez le bouton « Réinitialiser ». L'intégralité de la base SQLite locale est détruite instantanément.
  • Depuis Android : Paramètres → Applications → CryptoScan → Stockage → Effacer les données.
  • Désinstallation : la désinstallation de l'application supprime définitivement toutes les données associées.

Données publicitaires

Les annonces sont fournies par Google Mobile Ads. Vous pouvez à tout moment limiter ou supprimer les identifiants publicitaires utilisés :

  • Réinitialiser ou supprimer l'ID publicitaire : Paramètres Android → Confidentialité → Annonces → Supprimer l'ID publicitaire.
  • Révoquer le consentement : dans l'application, Réglages → Préférences de confidentialité (RGPD). Le formulaire Google UMP permet de retirer les consentements accordés.
  • Politique de Google : policies.google.com/privacy.

Demande par e-mail

Si vous souhaitez formuler une demande d'effacement ou exercer vos droits RGPD (accès, rectification, portabilité, suppression), écrivez à :

support@cryptoscan.app

Indiquez l'objet « Demande de suppression de données ». L'éditeur ne détenant aucune donnée personnelle, la réponse confirmera qu'aucune information n'est conservée à votre sujet. Délai de réponse : 30 jours maximum.

Ce qui est conservé

  • Par l'éditeur : aucune donnée utilisateur, aucun identifiant, aucun historique.
  • Par Google Mobile Ads : les journaux techniques liés à la diffusion publicitaire suivent la politique de conservation de Google, indépendante de l'éditeur. Voir policies.google.com/technologies/ads.
  • Sur votre appareil : uniquement les fichiers de sauvegarde que vous avez exportés vous-même (format .enc). Ils sont sous votre contrôle exclusif.
